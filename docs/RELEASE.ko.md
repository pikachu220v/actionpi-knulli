# 배포판 설치와 확인

[English](RELEASE.md) · [한국어](RELEASE.ko.md)

배포 파일은 비어 있는 카드 공간까지 수 GB씩 전송하지 않도록 XZ로 압축했습니다.
압축을 푼 이미지 크기는 6,069,178,368바이트입니다. 디스크 이미지에서 파일을 삭제해도
파티션 크기는 자동으로 줄어들지 않습니다. 압축은 비워 둔 공간을 효율적으로 저장합니다.

1. 같은 GitHub 릴리스에서 `.img.xz`와 `SHA256SUMS`를 내려받습니다.
2. 압축 파일의 체크섬을 확인합니다. Linux에서는 내려받은 파일들이 있는 폴더에서
   `sha256sum -c SHA256SUMS`를 사용합니다. Windows에서는
   `Get-FileHash -Algorithm SHA256`으로 계산한 값을 제공된 값과 비교합니다.
3. XZ를 지원하는 이미지 기록 프로그램을 사용하거나 먼저 IMG 압축을 풉니다.
4. 이미지를 SD 카드 전체에 기록한 뒤 Action Pi에 넣고 전원을 켭니다.
5. **첫 설치 시 부팅 이미지 이후 검정화면만 보여도 정상적인 설치 과정입니다.
   약 5분 기다리면 SHARE 확장과 설정 설치 중 한두 차례 자동으로 재부팅한 뒤
   메뉴가 표시됩니다. 걱정하지 마시고 전원을 끄지 않은 채 설치가 끝날 때까지
   기다려 주세요.**
6. 사용할 게임과 필요한 추가 BIOS를 넣습니다. 다운로드가 필요할 때 Wi-Fi를 켜고
   네트워크 정보를 입력합니다.

압축 해제한 이미지의 SHA256:
`cef5a6a24dc71286cbf77698a7e0b86bbe096244b714c7a1a50cc075b581202b`.
배포판 구성 명세와 바이너리 구성 파일의 해시는 `release/`에 있습니다.

소스 트리는 Git에 보관하고 큰 펌웨어 파일은 Releases에 올립니다.
[GitHub 릴리스 문서](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)에
따르면 개별 첨부 파일은 2GiB 미만이어야 합니다. 압축 이미지는 업로드 전에 이 제한을
확인했습니다. 개인용 안정판 IMG는 업로드하지 않습니다. `tools/verify-release.py`는
한 번의 스트리밍 읽기 과정에서 XZ 무결성과 압축 해제한 IMG의 SHA256을 검증하면서
압축 파일의 SHA256도 기록합니다.

이 수정판에서 임의의 상위 펌웨어로 일반 업데이트하는 경로는 검증하지 않았습니다.
다른 커널이나 루트 파일시스템을 시험하기 전에 백업을 보관해 주세요. 버전 숫자가
같다는 것만으로 기록된 보호 조건이 계속 유효하다고 판단할 수는 없습니다.

## v1.0.3 단축키

SELECT를 누른 채 볼륨 +/−로 밝기를 조절합니다. 해 아이콘·%·게이지는 조작 후 약 2.2초 뒤 사라집니다. 일반 볼륨은 SELECT 없이 조절합니다.

## v1.0.4

PPSSPP는 1.20.4입니다. 첫 설치 대기·밝기 단축키·SELECT+START 종료 방법은 그대로입니다.

## v1.0.5 ZRAM

서비스 메뉴에서 zramswap을 켜고 끌 수 있고 기본값은 꺼짐입니다. BOOT/ACTIONPI_ZRAM/DISABLED라는 빈 파일로 시작을 차단할 수 있습니다. BennuGD는 부팅 때 자동 연결합니다.


## v1.0.8

새턴 스탠드얼론 1.20.51 GLES의 설정 메뉴는 **L3(왼쪽 스틱 클릭)**로 열고 닫습니다.


## v1.0.8 r2

이번 입력 수정을 포함한 파일명은 `action-pi-knulli-v1.0.8-r2.img.xz`이며 CRC판은 `action-pi-knulli-v1.0.8-crc-ko-r2.img.xz`입니다. 이전 v1.0.8을 받았다면 r2를 다시 받아 주세요.


## v1.0.9

새턴 스탠드얼론 1.20.51 GLES의 설정 메뉴는 **L3(왼쪽 스틱 클릭)**로 열고 닫습니다.

Flycast 스탠드얼론은 Vulkan 기본이며 L3(왼쪽 스틱 클릭)로 설정 메뉴에 들어갑니다. BOOT에 ACTIONPI_FIXES/DISABLE_FLYCAST_STANDALONE_VULKAN 빈 파일을 만들면 GL 복구 경로를 선택합니다. 최종판의 GL 전환 자체는 별도 재시험하지 않았습니다.
